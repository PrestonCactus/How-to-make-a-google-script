# How-to-make-a-google-script
Google scripts are one of the best ways to use html files to get games, it also provides a free link so everyone can use it. Here i'll explain how to make one.

1. Go to google sheets

2. Make a new sheet

3. Click "Extensions"

4. Click "Apps Script"

5. Click on the "+" button on the same row as files

6. Click "HTML"

7. Name it "index" (google scripts will add the .html part for you)
