# How-to-make-a-google-script

I Probably wont update this

Google scripts are one of the best ways to use html files to get games, it also provides a free link so everyone can use it. Here i'll explain how to make one.

1. Go to google sheets

2. Make a new sheet

3. Click "Extensions"

4. Click "Apps Script"

5. Click on the "+" button on the same row as files

6. Click "HTML"

7. Name it "index" (google scripts will add the .html part for you)

8. Delete everything in "code.gs" and "index.html"

9. Copy the "code.gs" code ive included in this repository and paste it into "code.gs" in google scripts

10. You can change the name of the tab where it says "INSERT NAME OF TAB HERE"

11. Paste your html code into "index.html"

12. Click "Deploy" on the top right

13. Click "New Deployment"

14. Click the setting button in between "Select type" and "Configuration"

15. Click "Web App"

16. You can add a description and set to who has access.

17. Click "Deploy" at the bottom right and you can click the link to see the script in action

18. schools don't usually block individual google scripts so your safe!
